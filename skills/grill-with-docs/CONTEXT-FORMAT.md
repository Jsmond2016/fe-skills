# CONTEXT.md 格式

`CONTEXT.md` 是**纯术语表（glossary only）**：建立项目领域语言，让 Agent 与人对同一概念的叫法一致。**绝不包含实现细节。**

## 结构

```markdown
# <项目> 术语表

## <领域概念>

**规范术语**：<term>

**定义**：一到两句，精确。

**别名**：<别名 / 被废弃的表述>

**避免使用**：<含义含糊或被过度使用的说法>
```

## 规则

- 每个解析过的术语一条；语言精炼后原地更新。
- 保持零实现细节——不写文件路径、函数名、表结构。
- 惰性创建：仅在会话中某个术语被确定后才新增条目；若 `CONTEXT.md` 尚不存在，出现第一个术语时再创建。
- 多上下文仓库：根目录存在 `CONTEXT-MAP.md` 时，由它指向每个上下文的 `CONTEXT.md` 位置。
